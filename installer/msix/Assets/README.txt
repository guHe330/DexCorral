Asset Requirements for MSIX Package
====================================

The following image assets are required for the MSIX package.
These are placeholder files - replace with actual application icons.

Required sizes:
- Square44x44Logo.png (44x44 pixels) - Small tile/taskbar icon
- Square150x150Logo.png (150x150 pixels) - Medium tile
- Wide310x150Logo.png (310x150 pixels) - Wide tile
- StoreLogo.png (50x50 pixels) - Store logo

All images should be PNG format with transparency support.
Use the DexCorral application icon/branding for these assets.

To generate these assets:
1. Create a high-resolution source icon (512x512 or larger)
2. Scale down to each required size
3. Save as PNG with alpha channel
